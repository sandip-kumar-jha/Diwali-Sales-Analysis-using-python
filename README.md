# 🪔 Diwali Sales Data Analysis (Python Project)

## 📌 Project Overview :-

This project analyzes Diwali sales data to uncover customer purchasing behavior, high-performing products, and business insights using Python.

The goal is to help businesses understand:

* Which customers spend more
  
* Which products sell the most
  
* Which states generate high revenue

---

## 📊 Dataset Features:-

* User ID
  
* Gender
  
* Age Group
  
* Marital Status
  
* State
  
* Occupation
  
* Product Category
  
* Orders
  
* Amount (Sales)

---

## ⚙️ Tools & Technologies Used :-

* Python 🐍
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Collab

---

## 🔍 Key Analysis Performed :-

* Data Cleaning (handling null values, dropping unnecessary columns)
  
* Exploratory Data Analysis (EDA)
  
* Gender-wise analysis
  
* Age group analysis
  
* State-wise sales analysis
  
* Occupation-based purchasing trends
  
* Product category insights

---

## 📈 Key Insights:-

* Married women (age 26–35) from certain states are top buyers
* IT, Healthcare, and Aviation sectors contribute more to sales
* Certain product categories dominate overall revenue
